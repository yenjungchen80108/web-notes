# Check Physical Device

## 如何判斷是使用真實裝置（實體設備）還是虛擬裝置（虛擬設備）？

判斷使用者是否是透過「真實裝置（實體設備）」或「虛擬裝置（模擬器、模擬瀏覽器、開發工具）」訪問網頁，在純 Web 環境中無法百分之百準確判斷，但你可以透過以下幾種方式近似推估：

⸻

✅ 常見檢測方法

1. 檢查 User-Agent

許多模擬器會帶有可辨識的 User-Agent 特徵。

```js
const ua = navigator.userAgent.toLowerCase();

const isAndroidEmulator = ua.includes("sdk") || ua.includes("emulator");
const isIOSSimulator =
  ua.includes("x86_64") ||
  ua.includes("simulator") ||
  ua.includes("iphone simulator");
```

> ⚠️ 但使用者或工具可輕易修改 UA，因此不可靠。

⸻

2. 檢查硬體資訊（DeviceMemory、HardwareConcurrency）

```js
console.log(navigator.hardwareConcurrency); // CPU 核心數
console.log(navigator.deviceMemory); // 記憶體（GB）
```

> • 如果看到 非典型數值（如 1 核心、512MB），可能是虛擬設備。

> • 實體設備通常記憶體 >= 2GB，核心數 >= 2。

⸻

3. 觸控能力檢查

模擬器雖然可以模擬觸控，但部分參數異常或缺失：

```js
const isTouchDevice = "ontouchstart" in window || navigator.maxTouchPoints > 0;
```

⸻

4. Media Capabilities & Sensors

檢查是否支援真實感測器：

```js
// 是否有真實加速度感測器
if ("DeviceMotionEvent" in window) {
  // 可能是真實裝置
}
```

⸻

5. 螢幕尺寸 + UA 矛盾

有時候模擬器會出現「UA 顯示為 iPhone，但解析度異常」：

```js
console.log(window.innerWidth, window.innerHeight);
```

> 搭配解析度表可以大致推斷。

⸻

6. 開發者工具偵測（Chrome DevTools 模擬）

檢查 navigator.webdriver（自動化瀏覽器常見）：

```js
if (navigator.webdriver) {
  console.log("可能是自動化或模擬工具");
}
```

⸻

❌ 無法直接得知的部分：

| 想知道                                           | 可行性                        |
| ------------------------------------------------ | ----------------------------- |
| 使用者是否用模擬器（如 Android Studio Emulator） | ❌ 無法從瀏覽器精確偵測       |
| 是否使用真實裝置拍照                             | ❌ 除非開啟裝置權限並拍照     |
| 是否為開發模式 / Debugger 模式                   | ❌ 需搭配後端或 DevTools 偵測 |
| 是否 Root / Jailbreak 裝置                       | ❌ 僅能原生 App 偵測          |

⸻

✅ 小結建議

| 方法                      | 可行性        | 穩定性      |
| ------------------------- | ------------- | ----------- |
| User-Agent 判斷           | ✅ 基礎偵測   | ❗ 可被偽造 |
| navigator.webdriver       | ✅ 偵測自動化 | ✅ 穩定     |
| 解析度 + UA 矛盾          | ⚠️ 推測性高   | 中等        |
| DeviceMemory, TouchPoints | ✅ 作為參考   | 中等        |
