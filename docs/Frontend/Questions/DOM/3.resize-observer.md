# Resize Observer

## What is Resize Observer?

ResizeObserver 是一個現代瀏覽器提供的 API，用來監聽 DOM 元素尺寸（width / height）的變化，不需要用 polling（輪詢）或 window resize 事件就能即時獲得更新。它特別適合用於：

⸻

✅ ResizeObserver 的主要用途

| 使用場景                         | 說明                                                                       |
| -------------------------------- | -------------------------------------------------------------------------- |
| 📦 元件尺寸變化監聽              | 監聽某個區塊（如卡片、側邊欄、圖片）的寬高變化，並根據變化更新畫面或樣式。 |
| 📱 響應式排版 / 元件行為改變     | 元件根據自身尺寸做不同排版（而不是依靠整個視窗寬度）。                     |
| 🧱 瀑布流 / Masonry 排列         | 根據每個元素尺寸重排整體格局。                                             |
| 🧩 Canvas / Chart 自適應容器大小 | 當容器變化時，圖表或 canvas 可自動重繪。                                   |
| 🔧 開發可調整面板                | 用於拖拉、伸縮面板時觸發更新。                                             |

⸻

✍️ 基本語法範例：

```js
const box = document.querySelector("#myBox");

const observer = new ResizeObserver((entries) => {
  for (let entry of entries) {
    const { width, height } = entry.contentRect;
    console.log(`Box resized: ${width}px x ${height}px`);
  }
});

observer.observe(box);
```

⸻

🎯 與 window.onresize 的差異

| 項目     | window.onresize          | ResizeObserver                |
| -------- | ------------------------ | ----------------------------- |
| 監聽對象 | 瀏覽器視窗               | 任意 DOM 元素                 |
| 精準度   | 無法監控元素尺寸變化     | 可監控元素寬高變化            |
| 應用情境 | 頁面整體變化（e.g. RWD） | 元件細節變化（e.g. 動態內容） |

⚠️ 注意事項

- 它只會監聽「內容區塊」的尺寸，不包含 margin / border。
- 在大量元素同時變動時，觸發次數多，建議搭配節流（throttle / debounce）。
- 可能在 Safari 某些版本有延遲或 bug，需注意兼容性。
