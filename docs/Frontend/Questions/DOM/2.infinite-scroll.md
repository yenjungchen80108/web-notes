# Infinite scroll

## 滾動導航如何實作？

滾動導航（Scroll Navigation）是指當使用者在網頁中滾動時，導覽列可以根據當前滾動位置高亮對應的區塊連結，或是點擊導覽列項目時平滑滾動到該區塊。

以下是完整實作說明，適用於純 JavaScript 或 React 的 SPA 頁面：

⸻

🧱 頁面 HTML 結構

```html
<nav>
  <ul>
    <li><a href="#section1" class="nav-link">Section 1</a></li>
    <li><a href="#section2" class="nav-link">Section 2</a></li>
    <li><a href="#section3" class="nav-link">Section 3</a></li>
  </ul>
</nav>

<section id="section1">...</section>
<section id="section2">...</section>
<section id="section3">...</section>
```

⸻

✅ 實作功能 1：點擊時平滑滾動

```js
document.querySelectorAll(".nav-link").forEach((link) => {
  link.addEventListener("click", function (e) {
    e.preventDefault(); // 阻止預設跳轉
    const targetId = this.getAttribute("href");
    const target = document.querySelector(targetId);
    if (target) {
      target.scrollIntoView({ behavior: "smooth" }); // 平滑滾動
    }
  });
});
```

⸻

✅ 實作功能 2：滾動時高亮目前區塊

```js
const sections = document.querySelectorAll("section");
const navLinks = document.querySelectorAll(".nav-link");

window.addEventListener("scroll", () => {
  let current = "";
  sections.forEach((section) => {
    const sectionTop = section.offsetTop;
    if (pageYOffset >= sectionTop - 100) {
      current = section.getAttribute("id");
    }
  });

  navLinks.forEach((link) => {
    link.classList.remove("active");
    if (link.getAttribute("href") === `#${current}`) {
      link.classList.add("active");
    }
  });
});
```

⸻

💡 可選：用 IntersectionObserver 更高效（現代做法）

```js
const observer = new IntersectionObserver(
  (entries) => {
    entries.forEach((entry) => {
      const id = entry.target.getAttribute("id");
      const link = document.querySelector(`.nav-link[href="#${id}"]`);
      if (entry.isIntersecting) {
        document
          .querySelectorAll(".nav-link")
          .forEach((link) => link.classList.remove("active"));
        if (link) link.classList.add("active");
      }
    });
  },
  {
    threshold: 0.6,
  }
);

document.querySelectorAll("section").forEach((section) => {
  observer.observe(section);
});
```

⸻

🧑‍🎨 補充 CSS 效果

```css
nav {
  position: fixed;
  top: 0;
  background: white;
}

.nav-link.active {
  font-weight: bold;
  color: blue;
  border-bottom: 2px solid blue;
}
```

## 在行動裝置上實作 下拉刷新與 上拉加載更多

在行動裝置上實作 下拉刷新（Pull to Refresh） 與 上拉加載更多（Infinite Scroll / Load More） 是常見的互動模式，以下提供你在 Web 頁面（含 React/Next.js）中如何實作這兩種功能的清楚範例：

⸻

✅ 一、上拉載入更多（Infinite Scroll）

🌱 思路：

當使用者捲到底部時，自動觸發載入下一頁資料。

🔧 原生 JavaScript 實作：

```js
window.addEventListener("scroll", () => {
  if (window.innerHeight + window.scrollY >= document.body.offsetHeight - 100) {
    loadMoreData(); // 距離底部 100px 就觸發
  }
});

function loadMoreData() {
  // 這裡呼叫 API 或 fetch 新的內容
  console.log("Loading more data...");
}
```

🔧 React Hook 實作（簡易版）：

```js
import { useEffect } from "react";

export const useInfiniteScroll = (callback) => {
  useEffect(() => {
    const handleScroll = () => {
      if (
        window.innerHeight + window.scrollY >=
        document.body.offsetHeight - 100
      ) {
        callback(); // 執行載入
      }
    };

    window.addEventListener("scroll", handleScroll);
    return () => window.removeEventListener("scroll", handleScroll);
  }, [callback]);
};
```

⸻

✅ 二、下拉刷新（Pull to Refresh）

💡 桌面瀏覽器多數不支援，需要手動實作（可搭配 Touch 事件）

🌱 思路：

- 使用 touchstart, touchmove, touchend
- 當使用者從頂部往下滑動一段距離，觸發 refresh

🔧 原生實作（簡化版）：

```js
let startY = 0;
let distance = 0;
let isRefreshing = false;

window.addEventListener("touchstart", (e) => {
  if (window.scrollY === 0) {
    startY = e.touches[0].clientY;
  }
});

window.addEventListener("touchmove", (e) => {
  if (window.scrollY === 0) {
    distance = e.touches[0].clientY - startY;
    if (distance > 80 && !isRefreshing) {
      isRefreshing = true;
      triggerRefresh();
    }
  }
});

function triggerRefresh() {
  console.log("Refreshing...");
  // 請求資料後記得 reset
  setTimeout(() => {
    isRefreshing = false;
  }, 1000);
}
```

⸻

✅ 三、搭配 UI 庫推薦（更完整）

| UI 框架                                         | 支援方式                         |
| ----------------------------------------------- | -------------------------------- |
| React Query + useInfiniteQuery                  | 自動處理滾動載入                 |
| React Virtualized / react-window                | 長列表最佳化載入                 |
| Vant Mobile（Vue） / Ant Design Mobile（React） | 提供內建下拉刷新元件             |
| iOS/Safari                                      | 支援原生下拉刷新手勢（不用實作） |

⸻

✅ 四、在 Next.js 中的建議

- 上拉載入更多：可結合 useEffect + fetch 或 React Query。
- 下拉刷新：不建議自己硬寫，推薦搭配 UI 库或跳轉刷新（例如 router.replace(router.asPath)）。
