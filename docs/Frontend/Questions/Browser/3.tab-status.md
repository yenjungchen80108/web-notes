# Tab status

## 如何判斷目前頁籤是否為活躍狀態？

你可以使用原生的 document.visibilityState 和 visibilitychange 事件來判斷目前頁籤是否為活躍（visible）狀態。

✅ 判斷是否為活躍頁籤（使用 document.visibilityState）

```js
if (document.visibilityState === "visible") {
  console.log("使用者正在瀏覽這個頁籤");
} else {
  console.log("使用者已切換到其他頁籤或最小化瀏覽器");
}
```

⸻

✅ 監聽頁籤狀態變化（visibilitychange 事件）

```js
document.addEventListener("visibilitychange", () => {
  if (document.visibilityState === "visible") {
    console.log("回到頁籤：恢復播放、刷新資料等");
  } else {
    console.log("離開頁籤：暫停播放、停止輪詢等");
  }
});
```

⸻

🔍 document.visibilityState 的值有哪些？

| 值          | 意思                                           |
| ----------- | ---------------------------------------------- |
| 'visible'   | 使用者目前正在瀏覽這個頁籤                     |
| 'hidden'    | 使用者切到其他頁籤、最小化、或手機畫面關閉     |
| 'prerender' | （極少見）頁面仍在背景渲染中，尚未顯示給使用者 |

⸻

✅ 實務應用場景

| 場景                              | 做法                                     |
| --------------------------------- | ---------------------------------------- |
| 使用者離開頁籤時暫停影片/音樂播放 | pause() 當 visibilityState !== 'visible' |
| 使用者切回頁籤時重新整理資料      | fetch() 當 visibilityState === 'visible' |
| 長輪詢（polling）只在活躍時運行   | 控制 setInterval 開關                    |

⸻

📦 進階：React Hook 實作（可複用）

```js
import { useEffect, useState } from "react";

export function usePageVisibility() {
  const [isVisible, setIsVisible] = useState(
    document.visibilityState === "visible"
  );

  useEffect(() => {
    const onChange = () => {
      setIsVisible(document.visibilityState === "visible");
    };

    document.addEventListener("visibilitychange", onChange);
    return () => document.removeEventListener("visibilitychange", onChange);
  }, []);

  return isVisible;
}

// 使用方式
const isPageVisible = usePageVisibility();
```
